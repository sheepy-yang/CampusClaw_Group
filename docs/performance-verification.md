# 性能验证

本仓库提供有界、可重复的并发冒烟脚本，不预填或伪造性能结果。

## 执行

先启动完整环境，再运行：

```bash
make load-smoke
```

默认对健康检查和当前班级讲义列表发起 100 次请求、并发度 10，要求无失败且 p95 不超过 1500 ms。可按验收环境调整：

```bash
python3 scripts/load-smoke.py --requests 500 --concurrency 20 --p95-ms 2000
```

非演示环境通过 `LOAD_USERNAME`、`LOAD_PASSWORD` 和 `LOAD_BASE_URL` 注入测试账号及地址，禁止把密码写入文档或版本库。

## 结果记录

每次验收将脚本输出及以下上下文记录到外部作业附件；仓库只保留文字结论：

- 提交哈希与执行时间；
- CPU、内存和依赖服务规格；
- 请求数、并发度和 p95 门槛；
- 成功数、失败数、平均/p95/最大延迟；
- 失败请求对应的 `request_id` 与脱敏日志；
- 结论及后续优化项。
