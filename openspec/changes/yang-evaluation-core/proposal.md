# Proposal: yang-evaluation-core

## Why

杨瑾文负责「作业评价与班级分析」四项技能：多模态主观题批改、班级讲评、学习诊断、作答过程回放与原创性审查。需达到 README 验收约束，并具备可测试主路径。

## What

- 多模态批改：客观题规则判分；主观题异步转写 → 学生确认 → 步骤划分 / 首错 / 建议分；低置信度教师复核；改分保留前后记录；模型失败不丢提交
- 班级讲评：有效提交 &lt;5 不调模型；送模前匿名化；结果仅教师可见
- 学习诊断：事件样本 &lt;3 显示「样本不足」；每项诊断绑定证据事件；教师确认后才对学生开放
- 作答回放与原创性审查：仅 interval/manual 快照；相似片段证据；不自动生成违规结论

- 刘沛鑫：复习路径 / 追问辅导 / 课堂聚类 / 自适应闯关 / MCP 工具服务本体
